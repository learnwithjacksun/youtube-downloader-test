API Reference

Stream saver HTTP API

Two GET endpoints. Send a public media URL, inspect formats, then download the selected file. No API key.

Base URL

This page uses the API for the current environment. Local files and localhost talk to http://localhost:3000; the deployed site uses the production host.

Quick start

1. Call /info to detect the platform and list formats.
2. Call /download with the same URL and a format id. 

curl "http://localhost:3000/info?url=https%3A%2F%2Fyoutu.be%2FdQw4w9WgXcQ"

curl -L -o video.mp4 "http://localhost:3000/download?url=https%3A%2F%2Fyoutu.be%2FdQw4w9WgXcQ&id=mp4"

Try it

Paste any supported link. This calls GET /info with no platform hint, so the server auto-detects YouTube, Instagram, TikTok, Facebook, Twitter/X, and the rest.

GET /info

Auto-detects the host from url and returns preview metadata plus downloadable formats. Pass platform only when you want to skip detection (required for YTS search queries and Pinterest search text).

Query

Name Required Description
url yes Media URL, or a YTS / Pinterest search query
platform no Hint such as youtube, instagram, tiktok, facebook, twitter, pinterest, threads, yts. Auto-detect still wins if the URL belongs to another host.

JavaScript

const base = "http://localhost:3000";
const url = "https://youtu.be/dQw4w9WgXcQ";

const res = await fetch(`${base}/info?url=${encodeURIComponent(url)}`);
const info = await res.json();

if (!res.ok) throw new Error(info.message);
console.log(info.platform, info.formats.map((f) => f.id));

GET /download

Re-fetches the media, selects the format, and streams the file as an attachment. Response is binary, not JSON.

Query

Name Required Description
url yes Same URL or query you sent to /info
id no Format id from /info. If omitted, the first format is used.
platform no Same hint as /info

curl

curl -L \
  -o "video.mp4" \
  -D - \
  "http://localhost:3000/download?url=https%3A%2F%2Fyoutu.be%2FdQw4w9WgXcQ&id=mp4"

JavaScript

const params = new URLSearchParams({
  url: "https://youtu.be/dQw4w9WgXcQ",
  id: "mp4",
});

window.location.href = `http://localhost:3000/download?${params}`;

200 headers

HTTP/1.1 200 OK
Content-Type: video/mp4
Content-Disposition: attachment; filename="Never Gonna Give You Up.mp4"
